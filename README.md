# 오마이라벨

[웹에서 바로 사용하기](https://reikop.github.io/ohmylabel/)


국내 A4 라벨지를 브라우저에서 편집하고 인쇄하는 정적 웹 앱입니다. index.html을 Chrome/Edge에서 열면 실행됩니다. 배포에는 index.html, styles.css, app.js, precision.js, precision-ui.js, pdf-export.js와 data/, vendor/, assets/ 폴더가 필요합니다. 실행 중 외부 서버 요청은 없습니다. 라이브러리와 한글 글꼴을 로컬에 포함합니다.

## 지원 규격

A사 128개, F사 79개, 합계 **207개 품번**을 제공합니다. 같은 배치를 사용하는 품번도 포함됩니다. A4 세로의 일반 격자 사각형 및 원형·타원형을 지원하며, 품번·모양·칸 수로 검색할 수 있습니다.

기본 규격은 실물 출력 정확도를 보장하지 않습니다. 실제 용지와 시험 출력을 대조하고 필요하면 크기·여백·프린터 보정을 조정하세요. 특수 칼선, 혼합 배치, 구멍 및 A4 외 용지는 지원하지 않습니다. 사각형은 외곽 상자로 표시합니다.

## 정밀 인쇄

권장 경로는 **인쇄용 벡터 PDF**입니다. A4 페이지 크기와 mm 좌표를 직접 기록하고 나눔 글꼴을 포함합니다. 한글 복합 글리프 누락을 방지하기 위해 글꼴 전체를 포함하며, 사용한 글꼴에 따라 파일 크기가 커집니다. PDF 미리보기가 최종 줄바꿈·배치 기준입니다. 편집 화면과 브라우저 인쇄는 줄바꿈이 다를 수 있습니다.

1. **5지점 보정 · 실측 검증** → **보정 계산용 PDF · 1장**을 실제 크기 100%로 출력합니다.
2. 종이 왼쪽·위쪽부터 A–E 십자선 교차점까지 거리를 재서 입력하고 보정을 계산·적용합니다. 이 측정지는 기존 보정을 적용하지 않습니다.
3. 프린터·급지함·용지 설정별로 보정값을 저장합니다.
4. **보정 확인용 PDF · 10장**을 같은 설정으로 출력하고 새 측정을 시작합니다. 각 장의 다섯 지점을 입력합니다.
5. 50개 지점 모두에서 위치 오차가 0.5mm 이하면 사용자 실측 목표 충족으로 표시합니다. 좌우·상하 오차를 합친 직선거리 기준이며, 10장 미만은 합격으로 표시하지 않습니다. 기록을 JSON으로 저장할 수 있습니다.

5지점 보정은 X/Y 배율·위치와 일정한 기울어짐을 함께 계산합니다. 계산 모델의 잔차와 보정 후 실측은 별개입니다. 보정값이 바뀌면 이전 기록은 새 보정의 검증으로 인정하지 않습니다. 무작위 급지 편차·용지 공차와 측정 도구 오차는 보정으로 없앨 수 없습니다. **0.5mm는 검증 목표이며 보장값이 아닙니다.** [보정 원리와 실측 절차](docs/precision.md)를 참고하세요.

기존 브라우저 인쇄와 간단 보정도 사용할 수 있습니다:

- A4 / 세로 / 실제 크기 100% / 여백 없음 / 머리글·바닥글 해제
- 제조사 시작 좌표와 피치로 각 칸의 절대 위치 계산. 원본 숫자는 그대로 저장하고 CSS mm 출력만 소수점 6자리로 표현합니다.
- ‘프린터 정밀 보정’에서 보정이 적용되지 않은 100 × 100mm 측정지 출력
- 실제 가로·세로 길이와 종이 왼쪽·위쪽으로부터의 거리 입력
- X/Y 배율 및 위치 동시 보정 후 ‘외곽 시험 인쇄’를 라벨지와 겹쳐 확인

측정 사각형의 시작 좌표는 (20,20)mm입니다. 실측 길이가 w, 왼쪽 거리가 l이면 scaleX=100/w, offsetX=20-l*scaleX이며 Y도 같습니다. 보정은 종이 원점 기준으로 글자·좌표·크기에 함께 적용됩니다. 보정값은 프로젝트에 저장되고 미리보기는 원래 용지 좌표를 표시합니다. 측정지는 항상 보정 없이 1장, 외곽 시험지는 보정 적용 후 모든 칸을 1장 출력합니다.

보정은 일정한 배율·위치 오차를 줄입니다. 급지 기울어짐, 매 장의 편차, 종이 신축, 제조 공차까지 없애지는 못합니다. 실제 1mm 미만인지 검증하려면 같은 설정으로 여러 장을 출력하고 첫 행·마지막 행·네 모서리를 측정해야 합니다. 앱은 프린터 설정을 강제할 수 없습니다.

## 기능과 호환 범위

칸별 문구·글꼴·크기·색상·굵기·정렬, 전체 적용, 자동 저장, 시작 번호 제외, 인쇄 매수, JSON 프로젝트 저장/불러오기를 지원합니다. 시작 번호는 모든 일반 출력 페이지에 적용됩니다.

**제조사에서 저장한 디자인 파일 가져오기는 아직 구현되지 않았습니다.** 이미지·바코드를 포함한 객체 구조를 분석하고 원본 출력과 비교해야 합니다. [호환성 작업 범위](docs/import-compatibility.md)를 참고하세요. 현재 JSON 불러오기는 오마이라벨 프로젝트 전용입니다.

PDF는 긴 문구가 안전 영역을 넘거나 글꼴에 없는 문자가 있으면 오류를 표시합니다. 기존 브라우저 인쇄에서는 긴 문구가 잘릴 수 있습니다. 더 작은 규격으로 변경하면 초과 칸 내용이 제거되므로 중요한 작업은 파일로 저장하세요. 자동 저장은 브라우저·접속 주소별로 분리됩니다.

## 재현·검증

    node tests/app.test.cjs
    node tests/precision.test.cjs
    npm install
    npm test
    node scripts/generate-pdf-fixtures.cjs
    python -m pip install pymupdf
    python tests/verify-pdf.py

PDF 검증은 별도 엔진 PyMuPDF로 A4 크기, 벡터 외곽 좌표, 기울어짐 포함 변환, 글꼴 포함, 한글 글리프의 실제 렌더링, 10페이지 출력을 확인합니다. 샘플은 output/pdf/, QA 중간 결과는 tmp/pdfs/에 생성됩니다. DOM 테스트에는 jsdom을 사용합니다. 포함 라이브러리·글꼴 출처는 [THIRD_PARTY.md](THIRD_PARTY.md)에 정리했습니다.

테스트는 207개 템플릿의 A4 범위·마지막 칸 좌표·모양, 알려진 배율/위치 오차의 역보정, 측정지/외곽 출력, 이전 프로젝트 마이그레이션, 편집·저장·인쇄 설정을 확인합니다. 최소 DOM 어댑터를 사용하는 로직 테스트이며 실제 브라우저 레이아웃·프린터 출력·제조사 앱과의 동일성 검증은 포함하지 않습니다.
