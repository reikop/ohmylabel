# 제조사 디자인 파일 가져오기

목표: A사·F사에서 저장한 파일을 이미지·바코드까지 최대한 유지해 웹에서 편집·출력한다. 현재 기능은 미구현이며 라벨 규격 선택과 별개의 작업이다.

## 확인한 사실

- [F사 공식 Design Pro 9 설명](https://www.formtec.co.kr/m04_01/5)은 DGZ가 DGF 디자인 파일과 MDB 데이터 파일을 통합한 형식이라고 명시한다. 내부 컨테이너가 ZIP인지, 객체 데이터 형식이 무엇인지는 실제 파일을 확인하기 전에는 확정하지 않는다.
- A사 사용자 저장 파일의 형식·확장자는 아직 확인하지 못했다.
- 이미지·바코드가 들어 있는 사용자 저장 파일은 아직 확보하지 못했다.

## 필요한 비교 자료

각 제조사의 원본 저장 파일 1개 이상과 같은 파일을 A4·실제 크기 100%로 출력한 PDF. 프로그램 이름·버전도 기록한다. 샘플에는 한글 글상자, 삽입 이미지, 종류와 값이 알려진 바코드/QR, 도형·선 및 사용하는 경우 연결 자료와 여러 페이지를 포함한다. 테스트 데이터를 사용해도 된다.

## 구현 기준

1. 파일 확장자만 신뢰하지 않고 시그니처·버전·크기·컨테이너 구조 확인.
2. 원본을 수정하지 않고 객체 배열로 변환. mm 좌표/크기, 회전, 겹침 순서, 형식별 속성 보존.
3. 이미지 원본·알파·자르기·비율 보존. 외부 링크만 있는 이미지는 제공되기 전까지 누락 상태 표시.
4. 글꼴 대체와 줄바꿈 차이를 표시. 같은 글꼴이 없으면 완전 동일하다고 표시하지 않는다.
5. 바코드 종류, 데이터, 검사 숫자, 모듈 폭, 높이, 여백, 표시 문자열 유지. 독립 디코더로 원본 값과 대조.
6. 미해석 요소·연결 자료·미지원 버전을 가져오기 보고서에 표시. 임의 변환하거나 조용히 누락하지 않는다.
7. 편집 가능한 객체 변환과 원본 PDF 재인쇄 경로를 구분. PDF 재인쇄를 객체 편집이라고 주장하지 않는다.
8. 원본 PDF와 변환 출력을 같은 물리 단위로 렌더링하여 위치·크기·겹침 비교.

샘플 확보·분석 전에는 지원 확장자나 이미지·바코드 호환 완료를 UI에 표시하지 않는다.
