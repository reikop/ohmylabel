# 정밀 출력과 검증

## 출력 순서

`index.html`을 열고 **5지점 보정 · 실측 검증**을 선택합니다. 먼저 보정 미적용 PDF 1장을 출력합니다. A4 세로, 실제 크기 100%, 페이지에 맞춤 해제로 설정하고, 이후 검증과 라벨 출력에도 동일한 프린터·급지함·용지 종류·배율을 사용합니다. 드라이버 설정을 웹 앱에서 강제할 수는 없습니다.

십자선의 **교차점**을 종이의 왼쪽·위쪽 끝에서 측정합니다. 선의 바깥쪽 끝을 재지 않습니다. 기준점은 A(20,20), B(190,20), C(105,148.5), D(20,277), E(190,277)mm입니다. 입력칸의 예시 숫자는 실제 측정값이 아니며 빈칸은 거부됩니다. 입력 단위 0.01mm는 도구의 측정 정확도를 의미하지 않습니다.

보정 적용 후 10장 확인용 PDF를 출력하고 설정을 기록해 새 측정을 시작합니다. 장 번호 순으로 각 장의 A-E 실측 좌표를 입력합니다. 최대 오차는 `sqrt(dx² + dy²)`이고 전체 50점에서 0.5mm 이하일 때만 목표 충족입니다. 최대값과 RMS를 함께 표시합니다. 10장이 채워지기 전에는 합격으로 판정하지 않습니다. 사용자 입력에 근거한 결과이며 독립 인증은 아닙니다.

외곽 PDF를 실제 라벨지에 겹쳐 첫 행·마지막 행과 모서리도 확인해야 합니다. 일반 종이에서 구한 보정값이 다른 두께의 라벨 용지에서도 동일하다고 가정하지 마세요. 설정이나 용지를 바꿨다면 해당 조건에서 다시 측정합니다.

## 계산과 저장

좌표는 종이 왼쪽 위 기준 mm이며 내부에서는 반올림하지 않습니다. 다섯 점으로 출력기의 아핀 변환을 최소제곱 추정하고 역변환을 적용합니다. 배율·평행이동·일정한 회전/기울어짐을 표현할 수 있습니다. 계산 최대 잔차가 0.5mm를 넘거나 보정 허용 범위 밖이면 적용을 막습니다. 허용 범위는 배율 0.9-1.1, 교차축 계수 절댓값 0.03 이하, 위치 보정 절댓값 10mm 이하입니다. 이 제한은 비정상 측정 방지용이며 프린터 성능 사양이 아닙니다.

프로젝트의 `scaleX`, `scaleY`, `shearX`, `shearY`, `offsetX`, `offsetY`가 보정 행렬입니다. 이전 프로젝트의 누락된 교차축 값은 0으로 처리합니다. 프린터 프로필과 측정 세션은 `ohmylabel.precision.v1` 로컬 저장소에 보관됩니다. 세션에는 설정 설명·시각·보정값·보정 지문·장별 좌표가 기록됩니다. 다른 보정값에서는 해당 결과를 현재 검증으로 인정하지 않습니다. 설정이 물리적으로 바뀌는 것은 앱이 감지할 수 없으므로 새 측정을 시작해야 합니다.

## PDF와 화면의 차이

PDF 페이지는 210 × 297mm이며 `mm × 72 / 25.4`로 포인트로 변환합니다. 라벨은 벡터 글자, 시험 외곽은 벡터 선으로 작성합니다. 프린터 보정은 글자와 외곽 전체에 같은 행렬로 적용합니다. PDF 출력은 선택한 시작 칸과 매수를 따르며 외곽 시험은 모든 칸을 1장 출력합니다. 5지점 계산용은 무보정 1장, 검증용은 현재 보정 적용 10장입니다.

최종 줄바꿈과 정렬은 PDF 미리보기에서 확인하세요. PDF는 포함된 글꼴의 폭을 사용하며, 타원에서는 내부에 들어가는 직사각형을 안전 영역으로 사용합니다. 안전 영역 초과와 지원하지 않는 문자는 출력 전에 알려줍니다. 편집 화면의 브라우저 줄바꿈과 차이가 있을 수 있습니다. PDF 뷰어의 자동 축소를 막는 힌트를 포함하지만 실제 인쇄 설정은 직접 확인해야 합니다.

## 검증 범위와 다음 단계

소프트웨어 테스트는 라벨 규격 좌표, 계산 역변환, 보정 상태와 기록의 연계, PDF 구조 및 실제 글리프 렌더링을 확인합니다. 자동 PDF 좌표 검증 허용치는 0.0001mm이며 이것은 **파일 내부 수치 검사**입니다. 물리적인 인쇄 정확도를 뜻하지 않습니다. 실제 브라우저 레이아웃 및 프린터 출력은 아직 실기 검증하지 않았습니다.

제조사 저장 파일의 이미지·바코드 가져오기는 아직 구현하지 않았습니다. 다음 호환성 작업에는 A사/F사 각각의 실제 저장 파일과 동일 문서의 제조사 출력 PDF가 필요합니다. 객체 구조·글꼴·이미지 자르기·바코드 데이터와 여백을 비교해야 원본 충실도를 평가할 수 있습니다.
